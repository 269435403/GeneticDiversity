# 基因多样性：核心设计公约

> 最后更新：2026-07-30  
> 性质：高于阶段功能清单的长期设计约束；后续阶段与兼容开发不得违背。

## 1. 世界系谱优先

本模组模拟当前存档数百、数千年形成的遗传历史，而不是从已加载 GeneDef 中无差别随机。

任何随机可遗传变体必须首先使用当前存档已经实际存在的异种/族群 Endogenes，并按出现频率给予权重。世界里越常见的特征越容易扩散；低概率突变负责引入新特征，原版生育负责继续传承。

## 2. 原版与 HAR 同等适用

“当前存档已存在的族群”同时包括原版 Human/Xenotype 与 HAR Race/Xenotype。阶段 3 已把原版 Human 与 HAR Pawn 的 Endogenes 纳入同一 Race/Faction 来源快照；以后不得退回只扫描 `ThingDefOf.Human`。

HAR 的 `RaceRestrictionSettings.CanHaveGene` 与 `Pawn_GeneTracker.AddGene` Patch 拥有 Race 安全最终否决权。适配失败时必须保守跳过非 Human，而不是绕过限制。

## 3. 固定候选优先级

1. 当前存档实际 Pawn 的 Endogenes；
2. 同阵营同 Race ×4、同 Race ×2、其他已出现 Race 的标准基因 ×1；
3. 目标 Race 没有样本时，使用其 raceGenes/允许 Xenotype/FRD 正权重配置等低权重先验；
4. Common 位点先完整尝试上述世界系谱/先验主池；只有主池非空但对当前 Pawn 的候选全部不合法，或主池无法成功加入基因时，才进入目标 Race 的受限 Def 恢复池；恢复池不得提前合并进主池、不得压过 4/2/1 权重；
5. 仅在机制明确属于低概率突变时使用突变池；Mutation 路径不得被 Common 恢复池替代；
6. 候选不合法时少加或不加，不得放宽 Race、冲突、前置、代谢、暴力能力或 `AddGene` 最终裁决来凑满位点。

## 4. 自定义与结构基因

- 标准 Gene 可在目标 Race 明确允许时低权重跨 Race；
- 自定义 geneClass 默认只在同 Race 实际观察或明确声明时传播；
- 身体、头型、耳尾、渲染与外观结构类基因默认只在同 Race 传播；
- 阶段 4 的精确兼容可以进一步收紧或明确放行，但不能降低 HAR 最终裁决。

## 5. 永久禁止项

- 不从 `DefDatabase<GeneDef>` 无差别随机后直接加入 Pawn；
- 不删除或替换 Race/Xenotype/raceGenes 核心基因；
- 不把 Xenogenes 批量转换为 Endogenes；
- 不改写原版父母 50%/100% 遗传规则；
- 不污染怀孕、胚胎、多胎或成长舱共享的 GeneSet；
- 不硬引用可选 HAR DLL；
- 不调用 `AlienChanceEntry.Select/Approved` 建只读缓存；
- 不以母亲 Race 猜测 HAR 新生儿最终 Race；
- 不因候选被 HAR 拒绝而绕过 `AddGene` 最终防线。

## 6. 当前阶段关系

- 阶段 1：非新生儿生成时 0～3 位点，90% 世界常见/10% 突变；
- 阶段 2：原版 Human 真正出生时一次 10% 单基因突变；
- 阶段 3：当前存档 HAR Pawn Endogenes、4/2/1 权重、HAR 反射裁决与 Race 回退；
- 阶段 4：Kiiro、Milira、Wolfein、Ratkin、OA 等逐模组精确兼容，已完整验收和清理；
- 阶段 4.5：十一来源精确规则已完成游戏内确认、测试入口清理、Release 重建与运行副本同步；
- 阶段 5：FRD 可选反射联动、FCD 独立回归与随机基因生成修复均已完成游戏内验收；临时测试入口已删除，最终 Release 构建与运行副本同步完成；
- 阶段 6：尚未开始，只有收到用户明确指令后才进入。

## 7. 阶段 4 精确兼容边界

- 已知来源用本模组 `GD_RaceGeneCompatibilityDef` 描述，不修改或复制第三方 Def。
- 精确 Def 只在目标 Race 没有世界实际样本时提供低权重原生 Xenotype/Gene 回退；世界实际系谱仍最高。
- 精确 Race 已登记时，通用 HAR Xenotype 列表不能覆盖白名单；HAR raceGenes、CanUseXenotype 和 CanHaveGene 仍是必要安全层。
- 同一个 Race 可以合并多个可选来源规则，例如 Ratkin 的两套扩展；来源未加载时对应规则必须为零。
- Epona、Unicorn、Destrier、Epona-Milira、Unicorn-Milira 分池；本模组不 Patch Epona 的出生后 Xenotype 修正。


## 8. 阶段 4.5 十一来源兼容公约

- 精确来源仅依据第三方模组在 RimWorld 1.6 下实际加载的 Def；目录里“存在 XML”不等于游戏会加载。Moosesian 的 Biotech/ 文件未由 LoadFolders.xml 或默认 Defs/ 根接入，因此本阶段不登记。
- 十一个来源为 `keeptpa.NivarianRace`、`Solaris.RatkinRaceMod`、`OARK.RatkinFaction.OberoniaAurea`、四个 Kiiro 猫种来源、Dragonian、Axolotl、Yuran 与基础 Miho `miho.fortifiedoutremer`；规则仍只提供低权重 Def 回退和 Race 边界。`[SRC]Miho` 自身没有 GeneDef，只是依赖并引用基础 Miho。
- GD_CompatibilityRegistry 对显式同族基因与自动判定的非标准原生基因都执行同 Race 所有者边界；不能因 XML 漏列就让自定义 geneClass 跨 Race。
- 世界实际样本的 4/2/1 优先级必须继续高于任何阶段 4.5 Def 回退。
- Miho 规则登记 5 个核心可遗传 Xenotype、12 个核心来源 Gene，并在 Odyssey 存在时自动解析额外 1 个 Xenotype 与 3 个 Gene；六个 HAR `geneList` 身份/耳型基因只允许 Miho。`Gene_Miho_AdvancedAuditory` 与 `Gene_Miho_Naked` 保持普通标准基因处理，HairColor Gene 仍由正式世界池安全检查排除。`GetNamedSilentFail` 使 Odyssey 未加载时条件 Def 安全缺席。
- 当前是带 `GD_Phase45AutomatedTests.cs` 的临时验收版；未收到覆盖十一个 packageId 且由新版阶段总按钮生成的用户日志前不得删除测试源码，也不得把 Release 构建通过写成游戏内通过。

## 9. 阶段 5 FRD/FCD 联动公约

- 只通过反射读取 `yyyyy.mixedpeoplesfactions` 的公开只读成员，不引用 `MixedPeoplesFactions.dll`；缺失或签名变化时只警告一次并退回阶段 3。
- FRD 已完成最终 Race、PawnKind 与 Xenotype 选择；本模组只在 `GenerateGenes` 之后追加安全 Endogene 变体，绝不重新选择或覆盖。
- FRD 阵营/种族 Xenotype 正权重配置只在目标 Race 没有当前世界实际样本时提供总权重 0.5 的低权重基因先验；世界 4/2/1 系谱观察严格优先。
- 先验仍必须通过精确兼容、HAR `CanHaveGene`、冲突、前置、代谢与暴力能力安全检查。
- Common 主池在最多 20 次候选后仍无法加入合法基因时，才允许尝试受限恢复池；Human 恢复来源限于原版可遗传 Xenotype 的标准基因，HAR 恢复来源限于该 Race 的 raceGenes、精确兼容 Def 与允许 Xenotype。恢复池同样经过全部安全链，不得通过放宽规则制造成功。
- 恢复池是“主池失败后的保底入口”，不是新的同级权重来源；不得提前与世界 4/2/1 主池混合，也不得改变 90% Common / 10% Mutation 的位点分流。
- `yyyyy.factionculturaldiversity` 不向基因候选提供权重，不建立文化决定基因或基因决定文化的绑定，也不改变政治阵营。
