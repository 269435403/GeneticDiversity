## 1. 最短路线

阶段4的按钮全部是**只读**：不消耗随机数、不创建人物、不改人物、不改阵营、不改种族、不改异种类型、不改存档。

由于 `Ratkin Gene Expanded` 与 `[OA]Ratkin Gene Expand` 的 About.xml 明确互相不兼容，不能把六个来源强行放在同一个加载列表。建议分三次启动游戏：

1. **组合A（约5分钟）**：绮罗、米莉拉、沃芬、埃波娜及其依赖；点击 `一键执行阶段4全部只读测试`。
2. **组合B（约3分钟）**：NewRatkinPlus + Ratkin Gene Expanded；点击 `一键测试阶段4鼠族基因扩展精确边界`、`一键检查阶段4结构基因不会跨种族`、`一键检查阶段4来源卸载软降级`。
3. **组合C（约3分钟）**：NewRatkinPlus + OA 框架 + [OA]Ratkin Gene Expand；点击 `一键测试阶段4OA鼠族精确边界`、`一键检查阶段4自定义基因类不会跨种族`、`一键检查阶段4结构基因不会跨种族`。

三个组合的日志已经提交并由 Agent 完成判定。三组合合并明确失败为 0；绮罗族单项缺固定边界标记，但直接实际值、六来源总检查与阶段总汇总共同支持“带限定的通过”。原始证据与逐项结果见 `阶段4用户测试原始日志_2026-07-28.txt` 和 `阶段4游戏内验收记录_2026-07-28.md`。

## 3. 统一准备

### 3.1 必需内容

所有组合都需要：

1. `Harmony`；
2. `核心`；
3. `生物科技`；
4. `Humanoid Alien Races`；
5. 对应种族本体与基因补丁；
6. `基因多样性 (Genetic Diversity)` 最后加载。

组合A按实际需要加载：Kiiro Race + Kiiro Race Gene Patch；Milira Race + Milira Race Gene Patch；Wolfein Race + Wolfein Race Gene Patch；Epona Dynastic Rise。测试混血时必须同时加载 Milira Race Gene Patch 与 Epona Dynastic Rise。

组合B：NewRatkinPlus + Ratkin Gene Expanded。  
组合C：NewRatkinPlus + OA 所需框架 + [OA]Ratkin Gene Expand。  
不要在同一组合同时加载 Ratkin Gene Expanded 与 [OA]Ratkin Gene Expand。

### 3.2 存档

按钮全部只读，可以使用任意能进入游戏的测试档，不需要另存。按钮不要求地图上存在对应种族人物，因为它直接检查加载完成后的 Def 和正式兼容注册表。

### 3.3 开启原版开发工具

1. 按 `Esc` → `选项`；
2. 勾选 `开发人员模式`；
3. 回到游戏，点击顶部 `开关Debug操作菜单`；
4. 在搜索框输入本文给出的完整中文按钮名；
5. 需要看详细输出时点击顶部 `开关Debug日志`。

## 4. 按钮统一日志格式

每个按钮都会输出：

```text
===== 测试开始：名称 =====
测试目的：……
游戏状态影响：只读；不消耗随机数；不创建人物；不修改存档。
步骤1/2/3：……
步骤为什么有效：……
预期值：……
实际值：……
失败原因：无 / 具体原因
最终结论：通过 / 失败 / 未执行
===== 测试结束：名称 =====
```

- **通过**：当前已加载来源的规则与精确集合一致。
- **失败**：已加载来源缺少规则、Race/异种类型名称不匹配，或边界被突破。
- **未执行**：本次加载列表没有该可选来源；这不是失败，换到对应组合后再点。

## 5. 单项按钮说明

### 5.1 `一键检查六个精确兼容来源是否检测`

自动读取六个 packageId，并对比有效规则数量。已加载来源必须至少有一条有效规则；未加载来源必须是零规则。只读。

### 5.2 `一键测试阶段4绮罗族精确边界`

自动读取 `Kiiro_Race`，比较登记集合是否恰好为 `KiiroXenotype`。该步骤验证绮罗回退不会把 Baseliner 或其他异种类型当成绮罗核心池。

### 5.3 `一键测试阶段4米莉拉精确边界`

自动读取 `Milira_Race`，比较登记集合是否恰好为 `MiliraXenotype`。混血 Race 不在这个基础池内。

### 5.4 `一键测试阶段4沃芬精确边界`

自动确认：普通可遗传池只有 `Wolfein_Xenotype`；`Wolfein_MoonPhase` 对沃芬允许、对 Human 拒绝；`Wolfein_PureBlood` 被排除。覆盖纯血不可遗传与自定义基因类边界。

### 5.5 `一键测试阶段4鼠族基因扩展精确边界`

自动比较八个当前 1.6 可遗传鼠族异种类型的集合全等。测试读取的是游戏实际加载内容，不扫描 `1.6_unofficial` 或旧版本目录。

### 5.6 `一键测试阶段4OA鼠族精确边界`

自动确认七个普通 OA 鼠族异种类型继承了可遗传基类并进入精确回退；`OAGene_DeepSleep` 等自定义类仅鼠族可用；继承不可遗传生化基类的 `OAGene_BiochemicalRatkinI` 不被登记。OA 来源及其 Def 前缀统一写作 **OA / `OAGene_*`**。

### 5.7 `一键测试阶段4埃波娜精确边界`

自动比较：`Alien_Epona→Xeno_Epona`、`Alien_Unicorn→Xeno_Unicorn`、`Alien_Destrier→Xeno_Destrier`。不生成新生儿，也不调用或覆盖 Epona 的出生后身份修正。

### 5.8 `一键检查阶段4结构基因不会跨种族`

从已解析的精确原生池中筛选身体/外观结构基因，逐个确认原生 Race 允许而 Human 拒绝。没有合适来源时显示“未执行”。

### 5.9 `一键检查阶段4自定义基因类不会跨种族`

从已解析的精确原生池中筛选自定义 `geneClass`，逐个调用正式注册表，确认原生 Race 允许、Human 拒绝。没有合适来源时显示“未执行”。

### 5.10 `一键检查阶段4埃波娜米莉拉池不混淆`

需要 Epona 与 Milira Gene Patch 同时加载。自动确认 `Alien_Epona_Milira` 只有 `Xeno_EponaMilira`，`Alien_Unicorn_Milira` 只有 `Xeno_UnicornMilira`。

### 5.11 `一键检查阶段4来源卸载软降级`

自动检查所有当前未加载的已知来源都没有活动规则；若六个都加载，则改用一个不存在的哨兵 packageId。不会卸载模组、不会改加载列表。

### 5.12 `一键执行阶段4全部只读测试`

把以上安全只读项目串行执行。最后输出通过、失败、未执行数量。由于加载组合互斥，出现“未执行”是预期；对应来源必须在其动己的组合中另行得到“通过”。
