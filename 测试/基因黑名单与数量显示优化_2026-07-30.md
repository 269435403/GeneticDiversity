> 日期：2026-07-30

## 一、功能清单

### 1. 基因数量概率显示

**位置**：ModSettings → 基因多样性 → 全局强度设置下方

**预期效果**：
- 保守：0个45%，1个45%，2个14%，3个1%
- 标准：0个20%，1个55%，2个20%，3个5%
- 高：0个5%，1个35%，2个40%，3个20%

### 2. 基因黑名单

**位置**：ModSettings → 基因多样性 → 基因黑名单部分

**两个按钮**：
- 管理黑名单基因：按 defName 禁用单个基因
- 管理黑名单类别：按 GeneCategoryDef 禁用整个类别

**预期效果**：
- 点击按钮弹出浮动菜单，列出所有可用基因/类别
- 已禁用的显示 [已禁用] 标记
- 点击切换禁用状态
- 黑名单计数实时更新
- 设置持久化保存

### 3. 黑名单过滤生效

**预期效果**：
- 使用 Dev Mode 生成新人物时，黑名单基因不会出现
- 出生突变时，黑名单基因不会被选中
- 黑名单设置在游戏重启后保持

## 二、测试步骤

1. **概率显示测试**：
   - 打开 ModSettings → 基因多样性
   - 确认强度设置下方有概率分布文字
   - 拖动强度滑块，确认概率文字随之变化

2. **黑名单UI测试**：
   - 查看黑名单部分显示"(0 个基因，0 个类别)"
   - 点击"管理黑名单基因"
   - 选择几个基因（如 Nearsighted, SlowRunner）
   - 确认计数增加
   - 点击"管理黑名单类别"
   - 选择一个类别（如 Violence）
   - 确认计数增加

3. **黑名单过滤测试**：
   - 开启 Dev Mode
   - 使用"工具 → 生成人物"生成 10 个人物
   - 检查生成的人物是否含有黑名单基因
   - 如果出现黑名单基因，记录为异常

4. **持久化测试**：
   - 保存游戏设置
   - 完全退出游戏
   - 重新启动游戏加载存档
   - 打开 ModSettings 确认黑名单仍在

## 三、验收标准

- **通过**：上述 4 项测试全部符合预期，无红字错误
- **失败**：任一测试不符合预期，或出现相关红字
- **未执行**：因前置条件、环境或依赖问题无法完成测试
