# 阶段 4.5 Miho 基因复核（2026-07-29）

## 1. 来源关系

- HAR“已兼容”目录中的 `[SRC]Miho,Star Ring Corporation`：packageId `src.Core.markeazzyh`；自身实际 1.6 加载根中没有 `GeneDef` 或 `XenotypeDef`。
- `[SRC]Miho` 的硬依赖基础模组：`Miho, the celestial fox`，packageId `miho.fortifiedoutremer`，Workshop ID `2816826107`。
- 因此兼容规则以 `miho.fortifiedoutremer` 为唯一 `MayRequire`/`sourcePackageIds`，不能要求 `[SRC]Miho` 同时加载；`src.Core.markeazzyh` 只加入 `About.xml/loadAfter` 软排序。

Gene/Xenotype 定义位于 `1.6/Defs/BioDesu/XenotypeDefs.xml`，Odyssey 追加定义位于 `Odyssey/Defs/Xenotype.xml`。

## 4. 边界判断

Miho HAR Race Def 的 `geneList` 限制六个种族身份/耳型基因：四个核心耳型、`Gene_CelestialMiho` 和 Odyssey 的 `Ears_Voidborn_Miho`。兼容规则把它们显式列入 `sameRaceOnlyGeneDefNames`。

`Gene_Miho_AdvancedAuditory` 与 `Gene_Miho_Naked` 不在 HAR `geneList`，继续按普通标准基因处理。HairColor Gene 虽登记为 Miho 原生来源基因，但正式 `IsWorldPoolGene` 会因 `EndogeneCategory.HairColor` 排除，不会进入随机传播池。

所有 Odyssey Def 名可安全写入同一条规则：Odyssey 未加载时 `GetNamedSilentFail` 返回空并被解析器过滤；新版精确测试只在运行时 Def 实际存在时把条件项加入预期集合。

## 5. 结论

旧阶段 4.5 测试版没有兼容基础 Miho；这是本轮确认的唯一新增真实漏项。补丁后阶段 4.5 从十个来源扩展为十一个来源，总测试从 17 个单项扩展为 18 个单项。
