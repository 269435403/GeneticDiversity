# 基因多样性：阶段 2 白话测试方案

> 最后更新：2026-07-28  
> 面向第一次使用 RimWorld 开发者模式的测试者。  
> 当前状态：用户于 2026-07-28 反馈阶段 2 全部游戏内测试通过、无错误；详细日志与结论见 `阶段2游戏内验收记录_2026-07-28.md`。  
> 目标：确认真正出生时只判定一次 10% 单基因突变，且不污染怀孕/胚胎/多胎共享 GeneSet。

## 0. 先做安全准备

出生、怀孕、胚胎、成长舱、招募、加基因和移除模组都会改变存档。不要使用唯一正式档。

1. 主菜单只启用：Harmony → Core → Biotech → 基因多样性。
2. 新建测试世界，进入地图后暂停。
3. “菜单 → 保存 → 另存为”，保存为 `GD2_基线_不覆盖`。
4. 每个大项开始前再另存一个新名字，例如 `GD2_自然出生前`、`GD2_胚胎前`、`GD2_移除前`。
5. 任何红字先停止，不要继续覆盖存档。

**通过**：模组列表无依赖/加载顺序警告，进入地图无本模组红字。  
**失败**：找不到 DLL、Harmony Patch 报目标不存在、进入地图连续红字。

## 1. 开启开发者模式并找到本模组动作

1. 点“选项”。
2. 勾选“开发者模式（Development mode）”。
3. 回到地图，上方出现开发者按钮。
4. 鼠标悬停找到“打开调试操作菜单 / Open debug actions menu”。
5. 搜索“基因多样性”。

应看到至少五项：

- 清空基因池缓存；
- 立即刷新基因池缓存；
- 只读统计当前地图成人 Human；
- 只读查看第二阶段出生诊断；
- 只读测试第二阶段列表隔离。

## 2. 加载日志

1. 打开开发者日志，先清空。
2. 正常运行 5～10 秒。
3. 再看日志。

**通过**：只出现一次类似 `Phase 2 loaded` 的基因多样性加载消息；没有红字。  
**失败**：ApplyBirthOutcome Patch 找不到、参数签名异常、类型加载失败、每 tick 重复刷加载日志。

## 3. 只读列表隔离测试

此步骤不修改 Pawn/GeneSet，但会消耗少量随机数。

1. 当前地图至少放一名有基因追踪器的原版 Human。
2. Debug Actions 搜索 `只读测试第二阶段列表隔离` 并点击。
3. 打开日志，找到 `Read-only Phase 2 birth-list isolation test`。
4. 记录下面三项：
   - `sourceUnchanged`；
   - `separateReference`；
   - `exactlyOneAdded`。

**通过**：

- `sourceUnchanged=True`；
- 若 `mutationCopyBuilt=True`，则 `separateReference=True` 且 `exactlyOneAdded=True`；
- 若候选池空/全部非法而 `mutationCopyBuilt=False`，源列表仍必须不变；
- 没有 Pawn 基因被改变，没有红字。

**失败**：源列表改变、结果仍是同一引用、成功结果增加 2 个以上、点击后 Pawn 基因实际变化。

## 4. null genes 路径：只验证安全跳过

原版 `Create baby from parents` 源码会把 `genes` 参数传 null，因此这个入口不会触发阶段 2 突变。它用于验证本模组保持原版，而不是测试 10%。

1. 另存 `GD2_nullGenes前`。
2. 地图上准备两名成年原版 Human。
3. Debug Actions 搜索 `Create baby from parents`。
4. 按提示先点第一名亲代，再点第二名亲代。
5. 婴儿出现后，执行 `只读查看第二阶段出生诊断`。
6. 在日志中找到 Birth mutation diagnostics。

**通过**：

- 婴儿正常出现；
- `patchCalls` 增加 1；
- `nullGenesSkipped` 增加 1；
- `chanceRolls` 不增加；
- 没有本模组红字。

**失败**：null 路径崩溃、本模组自行调用父母遗传、chanceRolls 增加、婴儿出现额外阶段 2 基因。

## 5. 新档真实非 null GeneSet 出生

阶段 2 主测试必须使用真正保存了 GeneSet 的怀孕/胚胎流程，不能用上一节的 Create baby from parents。

### 5.1 建立正常怀孕

1. 准备可生育的成年原版 Human 双亲。
2. 通过正常游戏的恋爱/伴侣与生育意愿流程形成怀孕；不要用“Add Hediff”硬塞怀孕，因为那可能缺父母与 GeneSet 数据。
3. 怀孕出现后立即暂停并另存 `GD2_真实怀孕_出生前`。
4. 打开孕妇健康页，记录怀孕状态；若界面能查看胎儿/遗传信息，截图保存。
5. 记录双亲 Endogenes 与 Xenotype。

### 5.2 快速完成出生

1. 在确认是真实怀孕后，Debug Actions 搜索 `Give birth`。
2. 选择孕妇；该动作会立即改变游戏状态并生成婴儿。
3. 婴儿出现后暂停。
4. 检查婴儿“基因”页的 Endogenes/Xenogenes。
5. 执行 `只读查看第二阶段出生诊断`。

**通过**：

- 怀孕在出生前没有被本模组提前改写；
- 每个孩子相对原始遗传结果最多多 1 个基因；
- 新增项若存在，位于 Endogenes，不在 Xenogenes；
- `chanceRolls` 对这次合格出生只增加 1；
- 命中且成功加入时 `chanceHits` 与 `mutationAdded` 各增加 1；
- 未命中时 `chanceMisses` 增加 1，孩子完全走原版；
- 无红字，Race/Xenotype/混血状态正常。

**失败**：出生前预览已变化、一次增加多个基因、变成 Xenogene、一次出生投多次骰子、出生失败或红字。

## 6. 旧档已有怀孕升级测试

此项需要阶段 1 DLL 时保存的怀孕档；若没有现成旧档，记录“未构造”，不要伪造通过。

1. 用阶段 1 版本建立真实怀孕并保存，记录双亲与孕妇状态。
2. 退出游戏，把运行副本升级为阶段 2。
3. 读取旧档，先不要让出生发生。
4. 检查孕妇与双亲基因没有加载时变化。
5. 另存后让其真实出生。

**通过**：读档不会立刻改变任何旧 Pawn/怀孕 GeneSet；只在真正出生时判定一次；孩子最多多 1 个 Endogene。  
**失败**：读档即变基因、怀孕损坏、旧人物被回填、出生重复追加。

## 7. 胚胎测试

此项会创建和消耗胚胎，必须另存。

1. 用 Biotech 正常流程提取卵子并由成年原版 Human 父亲受精，得到 HumanEmbryo。
2. 胚胎生成后暂停，记录/截图胚胎显示的父母与基因信息。
3. 另存 `GD2_胚胎_植入前`，退出主菜单并重新读取。
4. 读取后再次检查胚胎信息，确认没有因加载本模组变化。
5. 用正常植入流程让胚胎进入怀孕并最终出生；若要加速，等怀孕真实存在后再用 `Give birth`。
6. 出生后检查孩子基因和阶段 2 诊断。

**通过**：胚胎在保存/读取/植入前的基因信息不变；孩子最多多 1 个 Endogene；胚胎本体未被永久 Add。  
**失败**：胚胎预览提前增加基因、读取后变化、植入失败、孩子增加多个或出现红字。

## 8. 成长舱测试

1. 准备一个正常受精的 HumanEmbryo。
2. 建造成长舱并把胚胎装入。
3. 确认成长舱已识别胚胎后另存 `GD2_成长舱_出生前`。
4. 选中成长舱，点击 Gizmo `DEV: Embryo birth now`。
5. 婴儿出现后暂停，检查基因并查看阶段 2 诊断。

**通过**：成长舱正常完成出生；该孩子的合格 ApplyBirthOutcome 只增加一次 chanceRoll；最多多 1 个 Endogene；无空引用/红字。  
**失败**：舱体卡住、出生失败、重复判定、源胚胎被提前改写。

## 9. 双胞胎/多胞胎列表隔离

原版 Human 没有稳定的普通玩家多胎入口时，此项允许作为高级构造测试，不要求手改存档。

最低必须完成第 3 节的只读列表隔离测试。若另一个已加载模组能稳定产生多胎：

1. 在仅测试副本中启用它；记录额外模组名称与版本。
2. 让两个孩子共享同一原始怀孕 GeneSet 出生。
3. 分别记录两个孩子与阶段 2 诊断。

**通过**：第一个孩子的突变不会污染第二个孩子的源列表；两个孩子各自独立判定，每人最多多 1 个。  
**失败**：两个孩子被强制共享同一新增基因、第二个孩子的源列表已被第一个修改。

## 10. 代谢、冲突、前置与过滤

这些边界很难仅靠普通游戏稳定构造，可作为高级测试；不允许手改存档。

可使用：

- `只读测试第二阶段列表隔离` 的日志中 `failure=` 和候选拒绝统计；
- 多次真实出生后的 `birth candidate rejections`；
- 开发者加 Endogene 先把亲代/胚胎基因组合推到接近代谢边界，再建立新胚胎。

**通过**：

- 代谢只在 `GeneTuning.BiostatRange.min/max` 内通过；
- 重复、双向冲突、缺前置、颜色、Inbred、超凡、bodyType/forcedHeadTypes 候选被拒绝；
- 候选不足时少加或不加，不放宽规则；
- 日志无 `IntRange.Includes`/访问性异常。

## 11. 10% 统计

### 基础验收

至少完成 20 次真实非 null GeneSet 出生，用诊断记录：

- 开始前 chanceRolls / chanceHits / mutationAdded；
- 结束后对应数字；
- 每胎孩子是否实际多 1 个 Endogene。

20 次样本只能确认“每胎一次、不会明显失控”，不能精确证明 10%。

### 可选高级统计

建议累计 200 次真实非 null GeneSet 出生：

- `chanceHits / chanceRolls` 应围绕 10% 波动；
- `mutationAdded / chanceRolls` 可以略低于 10%，因为命中后可能没有合法候选；
- 任一孩子都不得多于 1 个阶段 2 新增基因；
- 正常模式不应逐胎刷日志。

若 200 次过于耗时，可记录“未执行高级统计”，但不得声称概率已由游戏内大样本验证。

## 12. 保存、完全重启与读取

1. 找到一个确实获得阶段 2 新增 Endogene 的孩子。
2. 记录 Race、Xenotype、Endogenes、Xenogenes 与代谢。
3. 另存 `GD2_出生突变_保存读取`。
4. 完全退出 RimWorld，再启动并读取。
5. 对照记录。

**通过**：新增基因仍在 Endogenes；没有重复；Race/Xenotype/混血状态不变；无红字。  
**失败**：基因消失、变成 Xenogene、读档又追加一次或出现缺类型错误。

## 13. 移除回滚

只在另存的测试档执行。

1. 保存一个已出生且带阶段 2 原版 Endogene 的孩子。
2. 退出游戏并禁用基因多样性。
3. 读取该测试档。
4. 检查孩子与日志。

**通过**：孩子已有的原版 Endogene 仍存在；没有自定义类型缺失；以后不再产生本模组突变。  
**失败**：读档因本模组自定义存档类型报错、已出生原版基因消失。

## 14. 阶段 1 回归

按 `阶段1白话测试方案.md` 至少重测：

- 普通新 Human 的 0～3 位点；
- 战斗 Pawn 不因新增基因失去 Violent；
- Newborn GenerateGenes 继续跳过；
- ForcedCustomXenotype/强制基因请求继续跳过；
- 保存读取与原版遗传；
- 缓存刷新和成人 Human 只读统计。

阶段 1 曾通过不代表修改阶段 2 后自动继续通过。
