- 日期：2026-07-30
- 证据：`D:\RimWorldModding\临时存放\红字.txt` 和用户截图 `微信截图_20260730171236.png`

## 红字原因

`GD_Settings.SettingsAffectPawn` 在世界生成的阵营初始化期间读取 `Faction.OfPlayer`。此时玩家阵营尚未建立，RimWorld 的 `Faction.OfPlayer` getter 会主动输出 `Could not find player faction.`。因此这是时序错误，不是存档损坏或 HAR/FRD 冲突。

修复：不再读取 `Faction.OfPlayer`，改为使用 `faction.def.isPlayer` 判断阵营类型，在玩家阵营尚未创建的世界生成阶段也不会报红字。阶段6总测试同时新增了无阵营 PawnGenerationRequest 的回归检查。

## Debug Action 问号原因

阶段6新增中文字符串在写入 C# 源码时受 Windows 命令管道代码页影响，已在编译前变成字面量 `????`，因此游戏只能显示问号。

修复：将阶段6 Debug Action 标签、消息文本和设置分类改为 C# Unicode escape，避免再次经过命令行代码页。
