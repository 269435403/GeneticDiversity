# 阶段6设置窗口主菜单异常修复

- 日期：2026-07-30
- 原始证据：`D:\RimWorldModding\临时存放\红字.txt`
- 现象：在主菜单打开模组设置时，`Dialog_ModSettings` 填充失败。

## 原因

`GD_SettingsWindow.Draw` 为了显示“当前选中 Pawn 的阵营/种族强度覆盖”入口，无条件读取 `Find.Selector`。`Find.Selector` 内部需要 `Find.MapUI`，而主菜单的 ModSettings 窗口没有地图 UI，因此抛出 `InvalidCastException`。

## 修复

只在同时满足以下条件时读取 `Find.Selector`：

```csharp
Current.ProgramState == ProgramState.Playing && Find.CurrentMap != null
```

主菜单或世界视图无当前地图时，不显示“当前选中 Pawn”覆盖按钮，其他全局设置仍正常显示。
