## 0. 永久核心理念（后续 Agent 不得遗忘）

本模组模拟的是当前世界在数百、数千年间形成的基因传承。凡是随机选择可遗传变体，必须**优先从当前存档已经实际存在的异种/族群 Endogenes（系谱基因）中抽取并按出现频率加权**；原版 Human/Xenotype 与 HAR Race/Xenotype 在此原则上地位相同。只有世界系谱池为空、候选不兼容，或机制明确属于低概率新突变时，才允许使用 Def/Xenotype 回退池或突变池。

## 2. 阶段 1 已实现且已验收的机制

阶段 1 Patch 原版私有静态方法 `PawnGenerator.GenerateGenes(Pawn, XenotypeDef, PawnGenerationRequest)` 的 Postfix，只处理原版 `ThingDefOf.Human`。它跳过 Newborn、ForcedCustomXenotype、非空 ForcedEndogenes、非空 ForcedXenogenes、非 Human 和无基因追踪器 Pawn；不因普通 ForcedXenotype 单独跳过。

合格的新生成非新生儿 Pawn 抽取 0～3 个额外位点，概率为 20%/55%/20%/5%。每个位点 90% 从当前世界 Human 的 Endogenes 常见池抽取，10% 从原版突变池抽取；每个位点最多尝试 20 次。新增基因通过 `pawn.genes.AddGene(candidate, xenogene: false)` 成为 Endogene。

## 3. Endogenes 与 Xenogenes 的区别

**Endogenes（系谱基因）**是可进入生殖遗传流程的基因。原版 `PregnancyUtility.GetInheritedGenes` 只遍历父母的 `pawn.genes.Endogenes`：单亲拥有时约 50% 继承，双亲都有时 100% 继承，并处理前置、代谢、发色、肤色和近亲基因。

**Xenogenes（异种基因）**通常代表后天植入的异种胚基因。它们可以产生正常基因效果并参与覆盖关系，但原版父母遗传不会读取它们。Xenogene 与 Endogene 的区别主要是来源、存放区和是否自然遗传，不是“外观是否奇怪”或“是否有效”。

原版 `Pawn_GeneTracker.SetXenotype` 的关键逻辑是：

`AddGene(xenotype.genes[i], !xenotype.inheritable);`

因此基因放在哪个区由 `XenotypeDef.inheritable` 决定：

- Dirtmole（土鼹种）的 Def 明确写有 `<inheritable>true</inheritable>`，所以 `!true == false`，整套基因以 Endogene 加入。
- Hussar（骠骑种）没有写 inheritable；`XenotypeDef.inheritable` 是未初始化的 bool，默认值为 false，所以整套基因以 Xenogene 加入。
- Starjack（星旅种）同样未写 inheritable，默认 false，因此基因位于 Xenogenes。

这正是土鼹种和骠骑种/星旅种显示位置不同的原因。`SetXenotypeDirect` 只改变 Xenotype 身份字段，不会重新移动或添加基因。

## 4. 阶段 2 唯一目标与边界

阶段 2 只做一件事：**真正出生时，默认 10% 概率尝试增加最多 1 个兼容的原版突变基因，并把它作为 Endogene 传入新生儿生成。**

必须保持：

- 不重写原版父母遗传，不改变 50%/100% 继承规则。
- 不 Patch `GetInheritedGenes`，不 Patch 怀孕/胚胎基因预览。
- 不修改怀孕 Hediff 或 HumanEmbryo 保存的 GeneSet 本体。
- 不在阶段 1 的 Newborn GenerateGenes 路径追加 0～3 个基因。
- 每次 `ApplyBirthOutcome` 最多追加一个；未命中 10% 或无合法候选时完全保持原版。
- 不加入 HAR、设置 UI、第三方 Race、旧人物回填或自定义存档字段。

阶段 2 的突变候选推荐只取 `GD_WorldGenePool.Current.MutationGenes`，沿用 selectionWeight 加权和最多 20 次尝试；池空或全部不兼容时直接不突变，禁止放宽安全规则。

## 5. 推荐 Harmony 接入点与精确签名

RimWorld 1.6 当前原版方法为：

`public static Thing ApplyBirthOutcome(RitualOutcomePossibility outcome, float quality, Precept_Ritual ritual, List<GeneDef> genes, Pawn geneticMother, Thing birtherThing, Pawn father = null, Pawn doctor = null, LordJob_Ritual lordJobRitual = null, RitualRoleAssignments assignments = null, bool preventLetter = false)`

推荐显式绑定全部参数类型，避免未来重载歧义：

```csharp
using System;
using System.Collections.Generic;
using HarmonyLib;
using RimWorld;
using Verse;

[HarmonyPatch(
    typeof(PregnancyUtility),
    nameof(PregnancyUtility.ApplyBirthOutcome),
    new Type[]
    {
        typeof(RitualOutcomePossibility), typeof(float), typeof(Precept_Ritual),
        typeof(List<GeneDef>), typeof(Pawn), typeof(Thing), typeof(Pawn),
        typeof(Pawn), typeof(LordJob_Ritual), typeof(RitualRoleAssignments), typeof(bool)
    })]
internal static class GD_Patch_PregnancyUtility_ApplyBirthOutcome
{
    [HarmonyPrefix]
    private static void Prefix(
        ref List<GeneDef> genes,
        Pawn geneticMother,
        Thing birtherThing,
        Pawn father)
    {
        // 资格检查 → 10% 判定 → 复制列表 → 选择并验证最多一个候选 → 替换 genes 引用。
    }
}
```

原版方法内部把 `genes` 直接用作 `PawnGenerationRequest.ForcedEndogenes`；若它为 null，才调用 `GetInheritedGenes`。自然怀孕、分娩仪式、胚胎和成长舱通常传入已保存 GeneSet 的 `GenesListForReading`，而该属性就是内部可变列表。因此**绝不能直接 `genes.Add(candidate)`**。

安全顺序应为：

1. Biotech 活跃，`genes != null`。
2. 遗传母亲必须是原版 Human；父亲非空时也必须是原版 Human。
3. 每次调用只执行一次 `Rand.Chance(0.10f)`。
4. 创建 `List<GeneDef> working = new List<GeneDef>(genes);`。
5. 在 working 上尝试选择并验证一个候选。
6. 仅成功时 `working.Add(candidate); genes = working;`。
7. 失败或未命中时不改变原参数。

若 `genes == null`，阶段 2 初版应记录诊断并保持原版，不要在 Prefix 中自行调用 `GetInheritedGenes`，否则可能改变随机数消耗、预览一致性或其他模组补丁顺序。原版开发者动作 `Create baby from parents` 会走 null 路径，因此不能用它作为阶段 2 概率主测试入口。

## 9. 已知风险与回滚策略

已知风险：游戏更新改变 ApplyBirthOutcome 参数；其他模组调整 genes 参数或 Harmony 顺序；genes 为 null 的非标准出生不会获得阶段2突变；世界 MutationGenes 为空时实际加入率低于10%；直接改 GeneSet 列表会污染怀孕、胚胎和多胎；误在 GenerateGenes Newborn 路径启用阶段1会造成重复处理。

发生红字或回归时，先禁用新增 ApplyBirthOutcome Patch，不要删除或回滚 Pawn 已拥有的基因。阶段2不新增 GeneDef 和自定义存档字段，所以已经出生的突变只是普通原版 Endogene。代码回滚时删除新增出生文件、恢复被修改的 Validator/Metabolism/Diagnostics/Bootstrap，重新构建阶段1 DLL并白名单同步。测试必须使用另存档；不要在唯一正式存档上批量生育或调试生成。
